# Talitali CMS

Modern Content Management System built with Nuxt 3, Prisma, and TailwindCSS.

## Features

- 🎨 Modern Admin Dashboard
- 📝 WYSIWYG Editor (TinyMCE)
- 🖼️ Media Library
- 📊 Custom Fields System
- 🏷️ Categories & Tags
- 👥 User Management
- 🔐 Authentication (NextAuth)
- 🎯 SEO Optimized
- 📱 Fully Responsive
- ⚡ SSR & Static Generation

## Tech Stack

- **Frontend:** Nuxt 3, Vue 3, TailwindCSS
- **Backend:** Nuxt Server Routes, Prisma ORM
- **Database:** MySQL
- **Authentication:** NextAuth.js
- **Editor:** TinyMCE
- **Icons:** Nuxt Icon (Lucide)

## Deployment

This project is deployed on Railway.app with automatic deployments from GitHub.
